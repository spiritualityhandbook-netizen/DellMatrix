## 3. Idea model audit (before → after)

### Before

`Unit`: id, label, words, skin, x, y, sandbox…  
Create could be label-only → growth had little to aim at.

### After (foundation)

`Unit` adds:

- `detail: str` — what the idea is  
- `goals: List[str]` — what evolution should serve  

REPL create path accepts `detail:` and `goals:` segments.  
Persist v7 serializes both.  
Ringed growth includes goal tokens in affinity text so proposals lean on stated aims.

### Still open (next passes, not corner-cut claims)

- Hard refuse create with empty goals (policy switch)  
- Proposal objects carrying goals explicitly  
- Main daily job scheduler process  
- Multi-matrix “connect into Main” protocol
