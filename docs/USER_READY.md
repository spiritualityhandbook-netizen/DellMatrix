## Acceptance checklist (operator)

1. Open via `python launch.py` or launcher  
2. Type `tutorial` (or follow `docs/TUTORIAL.md`)  
3. Confirm: idea created · growth in Nursery · confirm · sphere · save · load · visual HTML opens offline  
4. Type `help` — short list works; `help more` for full  

If all four pass → **user-ready**.
