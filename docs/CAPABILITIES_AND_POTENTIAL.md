## 4. “Missing organs” — clarified

On a **full clone of this repo**, vital modules **are present and strong** (plane, pillars, lattice, ringed_growth, english_brain, etc.).

“Missing” in a sparse chat sandbox usually means **not on PYTHONPATH**, not “absent from GitHub.”

**Still gated by hardware (by design):** mic, camera, screen capture → folder-drop stand-ins under `form/state/`.

**Thin re-exports / faces:** `sense_intake.py` (re-export of body senses), `alpha_spirit.py` (face of floor_spirit).

Densify path: `git clone` / `git pull` this repo — see `docs/MISSING_ORGANS.md`.

## 7. How to run the whole program

```bash
git clone https://github.com/spiritualityhandbook-netizen/DellMatrix.git
cd DellMatrix
pip install -r requirements.txt   # if needed
python launch.py
# or
python -m form.dell_matrix.matrix_awake
python -m form.dell_matrix.auto_growth
python -m form.dell_matrix.live_host
```

Offline core does not require network.  
Internet: turn on gate / auto growth for far-wide research.
