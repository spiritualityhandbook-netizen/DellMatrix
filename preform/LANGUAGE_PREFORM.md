## Latin-Mandel creation paths (NEW — from early Pre-form)

### Leight (Lát-te · Late / Light)
**Create-path (aligns 08).**

Define a **new** Latin-style Mandel unit from scratch when the prefix, root, or suffix is **not yet defined** in the registry.

| Rule | Requirement |
|------|-------------|
| Gate | Must pass **Manual // Manuall** + Mandellafactors |
| Substance | Prefix and/or suffix each carry a **standalone** definition |
| Relation | Clash/opposition between parts is allowed — counts as a relation that can yield new perspective |
| SUS | Not any invented word; customs, restrictions, and True Mandel confirm required |
| Output | Architect number-confirm → True registry |

Pronunciation note (Architect): Late or Light — both proper.

### Loure (Lore / Lure)
**Change-path (aligns 04).**

Take a **non-Latin** word that **already** has a defined prefix/suffix sense and **adopt** that sense into Latin-Mandel.

| Rule | Requirement |
|------|-------------|
| Gate | Manual // Manuall + clash/test against existing category |
| Action | Map existing definition → Latin-Mandel slot without orphaning |
| SUS | Must not silently overwrite True terms |

**Naming mnemonic (Architect):** Leight ↔ Create(08) · Loure ↔ Change(04).

### Latin-Mandel standing rule
Does **not** require classical Latin etymology. Requires:
1. Prefix and/or suffix with standalone definition
2. Optional root
3. Manual classification
4. True Mandel confirm
