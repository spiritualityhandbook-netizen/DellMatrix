## 1. Work-memory vs preference-memory (Brain pattern)

| Kind | Keep for Mandell? | Map |
|------|-------------------|-----|
| **Work memory** — what ran, failed, corrections, artifacts | **Yes** | Checkpoint 27 · Stamp 34 · Shadow 17 · delta log |
| **Preference / taste profile** | Optional personal matrix only | Not forced into main |
| **Traceable source links** on every memory entry | **Yes** | Bind 14 · Map 15 · Keep 10 |
| **Overnight / batch synthesis** | Optional scheduled job | Cycle 06 + Distill 38 + Merge 21 |
| **Self-improve from corrections** | Yes with Architect oversight | Manual · Test 12 · Rollback 28 |

**Law:** Main matrix prefers **work/coherence memory** (fewer repeated mistakes). Personal matrix may store vibe/preferences.
