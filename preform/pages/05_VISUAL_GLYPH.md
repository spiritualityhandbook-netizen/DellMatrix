## Glyph Classes (locked taxonomy)

### FLOW (direction / RuPat)
```
→ ← ↑ ↓ ↔ ↕ ↖ ↗ ↘ ↙
⇢ ⇠ ⇡ ⇣ ⇒ ⇐ ⇑ ⇓ ⇔ ⇕
↪ ↠ ↣ ⟶ ⟵ ⟷ » « › ‹
╱ ╲ ╳
```
Use: sequence, diagonal RuPat, major jump (pair with `>` `>>` `>>>`).

### STRUCTURE (boxes / lattice / rooms)
```
─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼
═ ║ ╔ ╗ ╚ ╝ ╠ ╣ ╦ ╩ ╬
╭ ╮ ╯ ╰ ┊ ┋ ┆ ┇
⌜ ⌝ ⌞ ⌟ ⎾ ⏋ ⎿ ⏌
⌂ ⌁ ⌧ ⌫
```
Use: OpBox, cube projection, Guard frame, sealed Alpha frames.

### MARKERS (nodes / status / emphasis)
```
· ∘ ○ ◎ ● □ ■ ▢ ▤ ▥
★ ☆ ✦ ✧ ✴ ✵ ✶ ✷ ✸ ✹ ✺
◆ ◇ ▲ ▼ ▶ ◀ △ ▽
⚓ ⚖ ⚛ ⚑ ⚐ ☀ ☼ ☽ ☾
```
Use: center choice, growth stage, Temp bead, rare status (sparse).

### FILL / FOG / DENSITY
```
. · : ┊ │ ║ █ ▓ ▒ ░ ▀ ▄ ▌ ▐
⠁ ⠂ ⠃ ⠄ ⣿ (braille scale)
```
Use: Fog levels, Age/Fade pulse, progress.

### CONTROL / TECH (GodWorkSpace chrome only)
```
⌘ ⌥ ⌃ ⌤ ⎋ ⏎ ⌫ ⌦
⌚ ⌛ ⌨
```
Not core lattice law.

## Rules (True)

1. Structure ≠ Flow ≠ Marker in the same cell without explicit FlowBy (`:`).
2. Prefer monospace-stable glyphs (Box Drawing, Geometric Shapes, Arrows) for offline / phone.
3. One emoji maximum per cell if used at all.
4. New glyph → Manor only after Architect number confirm.
5. Density gradients and orbit rings are first-class for Temp and growth shells.

## Incorporation map

| Layer | How glyphs plug in |
|-------|---------------------|
| Dual Lattice | Structure = edges; Flow = RuPat; Markers = nodes/centers |
| Flower shells | Orbit rings `·∘○◎●`; negative space = force channels |
| Temp | Density gradient or C/W/H markers |
| Avatar / Expression | Markers + kaomoji from ExpressionField |
| GodWorkSpace | Monospace panels; legend uses this taxonomy |
| Notation | Glyph class is part of Notation audit |

## Phone / offline constraints

- CSS / terminal: `font-family: ui-monospace, monospace` + `white-space: pre`
- Avoid rare plane-1 glyphs that tofu on cheap fonts
- Braille and half-blocks allowed for dense micro-state
