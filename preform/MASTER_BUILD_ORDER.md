# Master Build Order

## Law
**Make as many phases as needed as we go.**  
No fixed ceiling. A new phase is created when a coherent slice of work is ready and Architect confirms scope.

## Standing process
1. **Preform** ideas (sift practical → assign phase)
2. **Architect confirms** next Code Phase scope (one message)
3. **Code that phase only**
4. **Audit / lock**
5. If more work remains → open **Code Phase N+1** (or a named side phase)

## Naming
- Prefer **Code Phase N** for main line
- Optional **named phases** (e.g. `Code Phase Avatar-Reach`, `Code Phase GodWorkSpace`) if a slice is large enough to stand alone
- Preform pages can be added anytime without renumbering code phases

## Gates (never drop)
- Floor: Alpha · Delta · Omega · Omni · Nova = Cheat only
- True registry writes only on Architect number confirm
- Offline-first for core path
- Multi-matrix: blank personal · optional main link · pull-only · peers
