# DellMatrix / Mandell Preform — What It Can Do

Status: TRUE · Living · 2026-07-28

## In one sentence
An offline, Floor-locked symbolic operating surface for Mandell: run a living core on your machine, hand others a Blank starter, and optionally snap improvements back into Main without overwriting the Floor.

## Floor (never changes)
**Alpha · Delta · Omega · Omni**  
Nova = Cheat only. English is display only; structure stays Mandel inside.

---

## Two products you actually use

### 1) Living core (you / power users)
```bash
python preform/code/29_COMPOSE_ENTRY.py
python preform/code/29_COMPOSE_ENTRY.py --smoke
```
Single offline runner that composes the working stack.

### 2) Blank Dell Matrix (give to others)
```bash
cd preform/seed
python check_seed.py      # integrity
python pack_seed.py       # zip → READY TO SEND
```
Recipient: unzip → `python blank_runner.py` → enhance only under `personal/` and `personal_code/`.

## What the living core can do today

| Capability | What it means in practice |
|------------|---------------------------|
| **Body / grid / reach** | Move, turn, pick up, place, stow, draw items on a small grid |
| **Pipeline queue** | Numbered steps; confirm when done; shows on the pane |
| **Persona lenses** | Aetheris (coherence), MANUELL (Dell/flow coach), The_Ancient (structural only — no decipherment) |
| **Token budget** | Seed strip and Show paths charge a budget; oversize reject/trim |
| **Dell / flow search** | Look up operators and flow symbols by number, name, manor |
| **Lexer (seed-shaped text)** | When you type `08[Create] >> 14[Bind]`, tokens are recognized and logged |
| **Render pane** | Floor, avatar, hand/inv, budget, seed, show, cmd, lex, pipeline, search, lens |
| **Offline** | Stdlib Python; no network required for core run |

## What it deliberately does *not* do

- Does not override the Floor
- Does not claim language decipherment (The_Ancient is structural only)
- Does not auto-sync personal work into Main (snap is voluntary)
- Does not require cloud or network for the critical path
