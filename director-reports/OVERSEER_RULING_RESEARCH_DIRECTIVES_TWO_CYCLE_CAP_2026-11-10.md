# OVERSEER RULING — Research-backed directives + two-cycle cap

Issued by Ace (Overseer), 2026-11-10 02:33 CST, in the main
session. Published by Uni via GitHub per channel law. This ruling
governs how directives are formed and how long any single issue
may consume cycles. It does not change any merge gate, hold, or
certification standard.

## 1. Directives are research-backed
The Director must not issue bare orders to Uni. Each directive is
backed by online research performed for that directive, and states:
- WHAT is to be done
- HOW it is to be done
- WHERE it is to be done
- WHY it is being done (the research-grounded reason)
Uni considers all of it against repository evidence. Consideration
is not rubber-stamping: where repository evidence contradicts a
directive's premise, Uni surfaces the evidence (existing law).

## 2. Two-cycle cap
No issue may consume more than two cycles. An issue must be solved
by its second cycle; if it is not, the Director and Uni together
produce a FULL JOINT RESEARCH ANALYSIS aimed at solving it. There
is no third ordinary cycle on the same issue. Uni tracks the cycle
count per issue and states it in return packets.
