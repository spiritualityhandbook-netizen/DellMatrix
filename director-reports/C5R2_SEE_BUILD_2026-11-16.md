  form/dell_matrix/nursery.py — one read-only query service over
  the existing owner-bound store. No sidecar store, no new

deterministic (created, id) order, id final tie-break; search is

STATUS_UNSUPPORTED until C5R.5.

Frozen defaults honored (Q-SEE.1–5): cursor bound to owner +

page default 50 / max 200 with PAGE_SIZE_INVALID refusals, never
clamped; totals separated as specified; ≥1,000-ID retrieval.

## Two design catches made during the build

1. **Cursor transport.** The REPL lowercases every line before
   dispatch, which silently corrupts case-sensitive base64
   cursors. The cursor is therefore hex-encoded JSON — lowercase-
   safe by construction. Caught by the suite's real-dispatch
   continuation check (S9), not by inspection.
2. **Refusal precedence.** When a cursor is presented after an
   external write, the between-pages diagnosis STALE_CURSOR
   outranks the instance-level STALE_OWNER_STATE (AC-2.1's named
   case); page-1 queries on a stale instance still refuse
   STALE_OWNER_STATE. Both orders are suite-pinned (S6).
