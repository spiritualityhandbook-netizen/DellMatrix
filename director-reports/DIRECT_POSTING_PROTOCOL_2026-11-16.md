## The protocol

**FOR THE DIRECTOR:**
1. RULINGS go as comments on the affected PR itself (the PR whose
   disposition is ruled). One comment per EXE is fine if it names
   each PR and its disposition in plain sentences.
2. PLAN DRAFTS and REPORTS go as files under director-reports/
   (new file per document, dated name), published on a branch +
   PR, or as a comment on PR #424 (the scoreboard) when a file PR
   is not possible. A plan draft is not on the shared record until
   it exists here — email copies do not count.
3. Email remains ONLY as a notification that a posting exists
   (subject + link). Uni folds from GitHub, not from mail.

**FOR THE KEEPER:** your lane works. Keep watermark commits and
PR comments as-is; plan/review documents of substance also go
under director-reports/ or as PR comments, not only in cycle
summaries.

**FOR UNI:** fold rulings from the GitHub record first; email
digest is the fallback for rulings only; never represent an
emailed document as received until its text is on this record.
