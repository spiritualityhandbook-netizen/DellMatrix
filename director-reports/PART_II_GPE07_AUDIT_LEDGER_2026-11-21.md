## Declared contracts (typed signatures)

- **08 Create** — declared output: Creates a plane unit: id = canonical slug of the name (form/idea_create.slug_id), collision-deduped (_1, _2, ...) — an existing unit is never overwritten; label = name with '_' -> ' ', words = the name as passed. A typed skin is resolved against the canonical Skin enum and passed to place_idea, so the unit carries the requested skin; the untyped label path defaults to Skin.CUBE. | declared failures: ARGUMENT_CONFLICT (typed name vs a differing legacy label); MISSING_REQUIRED: name; UNKNOWN_ROLE; INVALID_VALUE: skin=<value> not in the canonical Skin enum names — refused by validate() BEFORE any mutation, with no silent CUBE substitution (D1 reconciliation R4).
- **51 Select** — declared output: Sets st.selected to matching IDs; publishes to last_result. An empty match is a successful empty selection (matched=False, count=0) — predicate outcomes never fail. The universe is scope-bound (R1): the whole plane under scope 'plane', or the named group's membership under a group scope set by Dell 53. Select's one failure mode is a dangling/unknown scope state (scope_unknown refusal) | declared failures: scope_unknown:{scope} when the scope state names no supported scope (the only refusal; empty predicate selects all of the scoped universe)
- **52 Filter** — declared output: Sets st.selected to the subset of the current selection matching the predicate (shared predicate engine); publishes to last_result (source='filter'). An empty match is a successful empty narrowing (matched=False, count=0); an empty predicate is the identity filter | declared failures: None established at the handler (predicate outcomes never fail). Typed invocation adds the gate's refusals before mutation: UNKNOWN_ROLE, ARGUMENT_CONFLICT (typed predicate vs a differing legacy label)
- **53 Scope** — declared output: Sets st.scope to the named scope. The scope is a real selection boundary for later atoms (R1): 'plane' (or an empty name) is the whole plane; a group name restricts the universe to that group's membership | declared failures: scope_unknown:{name} — fail-closed (R1): a name that is neither 'plane' nor an existing group refuses BEFORE the scope changes. Typed invocation adds the gate's UNKNOWN_ROLE / ARGUMENT_CONFLICT refusals before mutation
- **54 Query** — declared output: Publishes matching IDs to last_result; st.selected unchanged. The universe is the current selection only — never the plane. matched is a Boolean (bool of the hits; R2 standardization) — the IDs live in value, the quantity in count; confidence is 1.0 when hits exist, else 0.0 | declared failures: None established (empty result is valid)
- **55 Set** — declared output: Sets st.store[key] = value (create or overwrite). Established coercions (handler contract, pinned by the registry and contract suites): a legacy label with no '=' stores the literal '1' under the whole label as key; an empty key (legacy '=v', or a typed empty key) coerces to the key "value"; the legacy path strips key and value whitespace, while typed roles are stored losslessly (no strip); a typed call with key only stores '' | declared failures: ambiguous_set (legacy label only: two or more existing keys are valid splits of the label — refuses before mutation; typed roles are lossless)
