# 1. HARMONIC CORE (the atlas itself)

Role confirmed by the Mandelbrot test: the program's
filing-and-finding layer for anything multi-scale.
Holds outcomes losslessly, layers them like octaves,
rebuilds deterministically (fingerprint = tamper alarm),
addresses without limit. It computes nothing and proves
nothing; it REMEMBERS, ORGANIZES, and lets any view be
re-derived and checked. Every system below files its
maps here; that is the sync Ace predicted, in its
general form: **the Harmonic Core is not one system
among the others — it is the shelf they all share.**

# 2. HARVEST CORE NETWORK (the body the atlas serves)

MECHANISM sync, point by point:
- The Network's organs are iterated processes with
  beats. Pulse ratios (Subkey 4 : Core 1 : Relay 0.25)
  are PERIODS — the atlas classifies each organ's beat
  behavior (steady / oscillating / runaway) exactly as
  it classifies Mandelbrot orbits. **An organ's behavior
  map is its health chart**; Profile's dragging signal
  (functional impairment) is read off the map's class,
  not a snapshot.
- DEMAND = choosing a region. The Demand Beat raises
  the systems a subject requires — in atlas language,
  selecting which maps and floors are foregrounded.
  SELECT-doctrine (growth law) and demand agree: never
  the whole atlas by default; a chosen region, receipted.
- TUNE, the slow lane, is the DEEP-BUDGET layer: the
  organ allowed to watch longest before verdicts — the
  atlas's high-budget floor, by design.
- WARD guards boundaries; behavior maps DRAW boundaries
  (the fractal frontier between calm and runaway).
  **WARD's watchlist is the set of behavior borders** —
  a design identity neither document had stated before
  this mirror.
- SEED VAULT = the cache of deep-budget maps: computed
  once, served forever (§ "compute once" of the
  Mandelbrot addendum, wearing an organ's name).
- RETURN/CLEAR: a bad excursion is an orbit that left
  its basin; rollback = return to a recorded earlier
  point of the orbit (checkpoint), never a rewrite —
  the same shape DuoBeta's missing rollback needs (§5).

# 3. VERITA (the missing Smith variable — DISCOVERY X1)

MECHANISM. The Smith tab (§5A of the Afterplan) was
parked on one missing piece: a native, measured
"how cleanly do two things meet" quantity for its
radius. **Verita already computes it.** Pair Verita =
solo integrity + vesica/Jaccard coherence of a pair,
with residue marks on weak meetings. Radius candidate:
mismatch = the pair's measured incoherence (from
verita_of_pair's own outputs). The angle's candidate
also surfaced in the mirror: growth and routing are
DIRECTIONAL (parent→child, sender→receiver), so a
signed asymmetry (how the meeting reads A→B minus
B→A) is computable from records the program already
keeps — the "which way it leans" coordinate. Neither
quantity is imported physics; both are DellMatrix's
own receipts. Verita, parked as a scorer, turns out to
be the Smith view's missing instrument. Falsification:
write the tab's data spec using ONLY existing receipts;
any quantity that cannot be sourced names the true gap.

# 4. SMITH VIEW (the atlas's reflection window)

PATTERN→MECHANISM via X1. In the atlas family the Smith

pair (cross, dock session, tool↔task) plotted by

# 5. ROUTE PATH (the two-way street — DISCOVERY X2)

MECHANISM, and the mirror's happiest find. Today Route
(59) flips a direction label; Branch follows it; routing
to an empty path is a safe no-op — a signpost with no
terrain. The atlas gives Route its terrain: **paths are
chosen over behavior maps** (through calm countries,
around runaway borders), the way Mandelbrot's external
rays thread from far away to exact landing points.
And the street runs back: **every executed route is a
trajectory, and trajectories are the raw samples from
which behavior maps are drawn.** Route feeds the atlas
its data; the atlas feeds Route its geography. Neither
half exists today; the two halves are each other's
missing organ. Falsification: check existing chain/route
receipts for enough trajectory data to draw one process's
terrain; if the receipts are too thin, THAT is the
finding (receipts must grow a trajectory field first).

# 6. DUOBETA (an orbit with a gate — DISCOVERY X3)

MECHANISM. DuoBeta's state iterates: outcomes → proposal
→ gate (≥3) → apply → reranking. Its long-run behavior
classifies in the atlas's three classes, and the middle
class is a NEW diagnostic: **oscillation** — learned
rerankings that flip-flop with period k. Today nothing
looks for it; a period detector over duo_ledger score
history would either find oscillation (a defect signal
with a shape) or certify its absence on record (also a
result). The known gaps gain basin language: rollback
(implicit today) = return to a recorded earlier orbit
point — HCN RETURN already designs that shape; the
missing disable/reset = an EXIT from a bad basin, to be
specified as such. DuoBeta's rows file into the atlas by
layer (round = floor), making learning itself a behavior
map over time: which evidence regions settle, which
oscillate, which drift. The f57v mirror from the earlier
study slots in here: growth rounds with mutation
receipts = filed orbit rounds, one floor per round.

# 7. VOYNICH (the mirror's laboratory and honesty school)

— DISCOVERY X6, sandbox-only, agreement rate measurable.

# 12. MANDELL CHAINS THEMSELVES (DISCOVERY X7)

MECHANISM candidate. A chain is an ORBIT through
Dell-space; a looping seed (Cycle/Loop) is an orbit
that may settle, cycle, or run away. Period detection
over hashed chain states gives every seed an ORBIT
RECEIPT: TERMINATED / PERIOD-k / NO-VERDICT-WITHIN-
BUDGET. Seed authors gain the debugger the Mandelbrot
programmers take for granted: run the seed, read its
class. Falsification is trivial and cheap: one known
terminating seed, one known looping seed, classify
both from state hashes alone.

# 13. THE KNOWLEDGE LIFECYCLE (the quiet skeleton)

PATTERN. STORED → ELIGIBLE → SELECTED → ROUTABLE →
USED → OBSERVED → LEARNED is a state machine every

(re-selection, re-observation) or escape (LEARNED

runaway class). The atlas files lifecycle maps per
knowledge family: where items stall (the STORED-never-
ELIGIBLE countries are as diagnostic as any runaway).
Routability (§5) is where this system plugs into Route.
