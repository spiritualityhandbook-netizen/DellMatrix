# Form intake law

When the user supplies a **form** (spec, codex, matrix, JSON behavioral surface):

1. **Analyze** structure honestly against Origin goals
2. **Score** each candidate piece

\[
S(c) = \phi(c)\,\rho(c)\,\lambda(c)\,\sigma(c)
\]

| Symbol | Meaning |
|--------|---------|
| ϕ | Practicality for offline Origin |
| ρ | Relatedness to Mandell / lattice / Floor |
| λ | Leverage on existing Program surfaces |
| σ | Safety (acceptance, CORE_SCOPE, no SIDE pull) |

3. **Implement high‑S only** (typically S ≳ 0.45–0.50)
4. **Defer** low‑S (full compilers, AIOps agents, unconstrained NPC stacks, etc.)
5. Stamp `form/NBD_LOG.md`

This law is permanent until explicitly revoked.
