# Mandell grammar

- Number = Dell gravity
- Bracket = Manifest
- `•` (U+2022) = ManifestSet separator
- Chain = same-number ordered ManifestSet
- Chainlink = positional zip of equal ManifestSets
- FlowSet longest match first: `>>>` `>>` `>` `:>` `<:` `<:>` `::` `:` `<<[Delta]`
- Mandellmoji is display alias. Execution does not require emoji.
- Mandellacell is a named reusable seed. Cycles fail `cell_cycle`.
- Tokenless is compression of the same semantic graph, not an empty language.
