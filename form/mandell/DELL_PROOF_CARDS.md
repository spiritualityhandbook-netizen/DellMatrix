## Deep-contract notes (D1 deepening circuits)

### 84[Copy]
- Deep contract proven (D1 circuit 4, d1_dell84_copy_test): store[copy_<src>] = deepcopy of the source; the destination is derived, never a caller argument; a missing source copies the name string itself; fallback order lab -> selected[0] -> "object"; publishes last_result; copies persist across save/load; English "copy A" routes its typed source through the generalized route (router arg-loss defect found and fixed in the same circuit).

### 85[Move]
- Deep contract proven (D1 circuit 5, d1_dell85_move_test): store[dest] = store.pop(src) — the same object relocates (identity, not a copy); lab is src>dest, partition on the first ">"; an existing destination is overwritten; dest == src is a named no-op success ("Move same identity", fresh matched result cell); failures malformed_move / move_missing publish failure cells; NOT in the English blocked set (86/87/88 are) — the English route executes "move A to B" with its operands and the moved state persists; at the REPL surface, however, the word "move" is captured by avatar navigation, so the REPL user path for 85 is the Mandell seed line.

### 86[Delete]
- Deep contract proven (D1 circuit 6, d1_dell86_delete_test): key = the whole lab; store wins over groups for a shared name (two deletes peel store, then group); NO_AUTHORITATIVE_RESULT — even a successful delete publishes an explicit non-matched result cell, distinct from the failure cell that carries delete_missing:{key} (empty key: delete_missing:empty — signature failures text synced to this truth in the same circuit); English delete is blocked_with_reason (operand-confirmation policy) at the route and at the REPL, and negated English never becomes a delete intent; deletions persist.

### 87[Replace]
- Deep contract proven (D1 circuit 7, d1_dell87_replace_test): identity rename old>new; an occupied destination REFUSES (replace_occupied:{new}, zero mutation — the MPC-012 §0 / MPC-011 J-decision in the executor's comment; the deliberate contrast with Dell 85 Move, which overwrites); replace_missing:{old} for an absent source (bare form: replace_missing:); empty new and new == old are no-op successes; signature failures text + derived_from range synced to the code in the same circuit (the refusal was missing from the signature); English replace is blocked_with_reason; renames persist.

### 88[Patch]
- Deep contract proven (D1 circuit 8, d1_dell88_patch_test): UPDATE-ONLY targeted write — an absent key fails patch_miss:{key} and is never created (the contrast with Dell 55 Set, which creates); first '=' splits, the value keeps further '=' characters and is stored RAW (key stripped, value not); an empty value is legal ('' stored, key survives); patching replaces the value's type wholesale (a list cell becomes the raw string); signature derived_from synced to the real arm (208-227) and its output now states the update-only law; English patch is blocked_with_reason; patches persist.
