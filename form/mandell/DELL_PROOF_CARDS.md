## Typed signatures (roles / output / failures)

### 08[Create] — Instantiate
- roles: name:string (required), skin:enum
- output: Creates a plane unit: id = canonical slug of the name (form/idea_create.slug_id), collision-deduped (_1, _2, ...) — an existing unit is never overwritten; label = name with '_' -> ' ', words = the name as passed. A typed skin is resolved against the canonical Skin enum and passed to place_idea, so the unit carries the requested skin; the untyped label path defaults to Skin.CUBE.
- failures: ARGUMENT_CONFLICT (typed name vs a differing legacy label); MISSING_REQUIRED: name; UNKNOWN_ROLE; INVALID_VALUE: skin=<value> not in the canonical Skin enum names — refused by validate() BEFORE any mutation, with no silent CUBE substitution (D1 reconciliation R4).
- derived_from: form/mandell/executor_leaf.py:place_idea:60-71

### 51[Select] — Select target(s) from current scope
- roles: predicate:string
- output: Sets st.selected to matching IDs; publishes to last_result. An empty match is a successful empty selection (matched=False, count=0) — predicate outcomes never fail. The universe is scope-bound (R1): the whole plane under scope 'plane', or the named group's membership under a group scope set by Dell 53. Select's one failure mode is a dangling/unknown scope state (scope_unknown refusal)
- failures: scope_unknown:{scope} when the scope state names no supported scope (the only refusal; empty predicate selects all of the scoped universe)
- derived_from: form/mandell/query_ops.py:apply_query:14-22

### 54[Query] — Retrieve information without mutation
- roles: predicate:string
- output: Publishes matching IDs to last_result; st.selected unchanged. The universe is the current selection only — never the plane. matched is a Boolean (bool of the hits; R2 standardization) — the IDs live in value, the quantity in count; confidence is 1.0 when hits exist, else 0.0
- failures: None established (empty result is valid)
- derived_from: form/mandell/query_ops.py:apply_query:28-32

### 56[Get] — Retrieve explicit value/state
- roles: key:string (required)
- output: Publishes st.store[key] to last_result; read-only. Three-state read: ok (matched=True), empty (stored "" — matched=False, error="empty"), missing (key absent — matched=False, error="missing"). The atom itself returns ok=True in all three states; the miss lives in the result cell
- failures: missing (key not in store), empty (stored value is ""), both reported in the result cell with matched=False; no mutation
- derived_from: form/mandell/query_ops.py:apply_query:35-44

### 57[Compare] — Structured comparison between >=2 targets
- roles: expression:string (required)
- output: Publishes comparison result to last_result (value = the bool, plus a mode field: number / string / boolean / missing / type_mismatch). Operands resolve from literals, store keys (bare or store:), count (the selection size), selected, context, and last_result (the previous cell's matched)
- failures: type_mismatch (incompatible operand types — the atom FAILS, ok=False); a missing operand is soft: the atom stays ok=True and the cell carries error="missing"
- derived_from: form/mandell/query_ops.py:apply_query:45-53

### 58[Match] — Pattern/semantic matching
- roles: pattern:string
- output: Sets st.selected to pattern matches; publishes to last_result (matched is a Boolean, as Dell 54; the IDs live in value). DESTRUCTIVE narrowing: dropped ids leave the selection. The pattern test is the SHARED predicate engine (as Select/Query): case-insensitive substring OR underscore-prefix, so a spaced pattern ('garden gate') matches the underscored id (unified by reconciliation R3)
- failures: None established (empty result is valid)
- derived_from: form/mandell/query_ops.py:apply_query:58-62

### 67[Any] — Existential/set-any condition
- roles: predicate:string
- output: Publishes boolean to last_result (value = matched = the hit; count = selection size). Read-only. On an empty selection Any is False for every predicate
- failures: None established
- derived_from: form/mandell/query_ops.py:apply_query:65-69

### 68[All] — Universal/set-all condition
- roles: predicate:string
- output: Publishes boolean to last_result (value = matched = the hit; count = selection size). Read-only. On an empty selection All is True for every predicate (vacuous truth)
- failures: None established
- derived_from: form/mandell/query_ops.py:apply_query:70-74

### 69[None] — Explicit absence/zero-match condition
- roles: predicate:string
- output: Publishes boolean to last_result (value = matched = the hit; count = selection size). Read-only. None is exactly not-Any on the same state (De Morgan pair with Dell 67); on an empty selection None is True
- failures: None established
- derived_from: form/mandell/query_ops.py:apply_query:75-79

### 84[Copy] — Duplicate without consuming original
- roles: source:string
- output: Creates st.store['copy_'+src] as deepcopy of source; original intact
- failures: None established (always succeeds; missing src copies the string itself)
- derived_from: form/mandell/spectrum_ops.py:apply_spectrum:103-109

### 85[Move] — Relocate ownership/location/state
- roles: source:string (required), destination:string (required)
- output: Moves st.store[src] to st.store[dest]; identity preserved
- failures: malformed_move (missing src/dest), move_missing (src not in store)
- derived_from: form/mandell/spectrum_ops.py:apply_spectrum:110-125

### 86[Delete] — Explicit controlled removal
- roles: key:string (required)
- output: Removes key from st.store or st.groups
- failures: delete_missing:{key} (key not found); empty key reports delete_missing:empty
- derived_from: form/mandell/spectrum_ops.py:apply_spectrum:126-142

### 87[Replace] — Atomic key rename old to new
- roles: old:string (required), new:string
- output: Renames st.store[old] to st.store[new or old] (identity preserved); an occupied destination refuses with zero mutation
- failures: replace_missing:{old} (old not in store), replace_occupied:{new} (destination occupied — refuses, zero mutation)
- derived_from: form/mandell/spectrum_ops.py:apply_spectrum:176-207

### 88[Patch] — Partial targeted modification
- roles: key:string (required), value:string (required)
- output: Sets st.store[key] = value (partial targeted modification; update-only — an absent key fails, it is never created)
- failures: patch_miss:{key} (key not in store)
- derived_from: form/mandell/spectrum_ops.py:apply_spectrum:208-227

## Deep-contract notes (D1 deepening circuits)

### 08[Create]
- D1 circuit 15 DEEP NOTE: Create mints plane units through the leaf executor's place_idea with the canonical slug (lowercase, non-alnum runs to '_', 40-char cap, fallback 'idea') and collision DEDUP (_1, _2, ...) — an existing unit is never overwritten; label is the name with '_' -> ' ', words is the name as passed. Typed law: name required, label/name conflicts fail with ARGUMENT_CONFLICT. SKIN (R4 corrected contract): validate() checks enum membership (skin is the registry's only enum role) against the canonical Skin enum — which has NO UNKNOWN member — and the executor wires the resolved skin into place_idea, so a typed skin lands on the unit; a non-member value refuses with INVALID_VALUE before any mutation, never a silent CUBE substitution; the untyped label path still defaults to Skin.CUBE. Creation is in-memory until Dell 10 saves; Program.load restores. In the REPL, English 'create a garden' takes the strong-idea door: the whole phrase becomes the name (id create_a_garden) with a strength report; the typed-chain Mandell line printed beside it is an echo, not the execution.

### 51[Select]
- Deep contract proven (D1 circuit 9, d1_dell51_select_test; scope semantics corrected by reconciliation R1, d1_recon1_scope_test): the universe is SCOPE-BOUND — the whole plane under scope 'plane', or the named group's membership (plane-intersected, plane order) under a group scope; a predicate filters by case-insensitive substring OR underscore-prefix (a spaced predicate matches the underscored id by prefix) and can narrow within the scope but never widen past it. Select REPLACES the selection, never appends; a no-match predicate is a successful empty selection (matched=False, count=0). Its one failure mode is a dangling scope (scope_unknown refusal, fail-closed). English select routes and executes (not blocked); the selection persists.

### 53[Scope]
- RECONCILIATION R1 NOTE (d1_recon1_scope_test): Scope establishes the selection boundary Dell 51 honors. Supported names are explicit: 'plane' (the default; a bare Scope restores it) or an existing Dell 82 group name. An unknown name refuses with scope_unknown:{name} and leaves the scope unchanged — a scope never silently widens to the whole plane. Ungrouping the active scope group leaves the scope dangling and Select refuses until it is reset. Scope and groups are core_ii durable state (save/load preserves the contract).

### 54[Query]
- Deep contract proven (D1 circuit 10, d1_dell54_query_test): READ-ONLY search of the current selection — the universe is st.selected only, never the plane (an idea placed after the Select is invisible); the selection is byte-identical after any query (contrast Dell 58, which rewrites it); matched is a Boolean (bool of the hits — standardized by reconciliation R2; the IDs live in value, the quantity in count); confidence is exactly 1.0 with hits, 0.0 without; Query never fails (empty selection and no-match are valid empty results); there is NO English surface — 'query garden' becomes the Dell 9 question intent and is refused, 'find garden' goes to Dell 56; the seed line and typed invocation are the only paths.

### 56[Get]
- Deep contract proven (D1 circuit 11, d1_dell56_get_test): a THREE-STATE read — ok (matched=True), empty (stored "" — matched=False, error="empty"), missing (matched=False, error="missing") — and the atom returns ok=True in ALL three states; the miss lives in the result cell, not the atom (contrast Dell 86, whose missing key fails the atom); bare Get falls back to the LAST INSERTED store key ("" on an empty store); values return by identity; Get never mutates the store; English get/find DO reach 56, but the documented ARGUMENT_LOSS residual lowercases the operand ('get A' reads 'a') — pinned at the route and in the literal REPL as the circuit-3 residual surfacing on the read path.

### 57[Compare]
- Deep contract proven (D1 circuit 12, d1_dell57_compare_test): typed comparison over resolved operands (literals, store keys, count, selected, last_result); a lab without an operator head is rewritten to eq: of its first two tokens (further tokens dropped); type_mismatch is the ONE hard failure (the atom fails) while a missing operand is soft (atom ok, cell error='missing'); the cell carries a mode (number/string/boolean/missing/type_mismatch); a bare Compare is vacuous truth (empty == empty); Compare is the query cluster's composition reader — count reads Dell 51's selection and last_result reads any previous Dell's cell, both proven live; no English surface ('compare...' becomes the Dell 9 question intent).

### 58[Match]
- Deep contract proven (D1 circuit 13, d1_dell58_match_test): DESTRUCTIVE narrowing of the selection by pattern (the dual of Dell 54's read-only search); chained Matches intersect; empty pattern is the identity; Match never fails; matched is a Boolean (as 54; R2 standardization); the pattern test is the SHARED predicate engine (unified by reconciliation R3): the spaced pattern 'garden gate' matches [garden_gate] under Match exactly as under Select — same text, one engine, same answer; no English surface; the narrowed selection persists.

### 67[Any]
- D1 circuit 14 DEEP NOTE: Any answers whether AT LEAST ONE selected id matches the shared predicate engine; value = matched = the hit, count = selection size, source 'any'. On an empty selection Any is False for every predicate; a bare predicate on a non-empty selection is True, so bare Any reads as 'is the selection non-empty'. Read-only. Dell 69 is its exact De Morgan dual (proven in the 67/69 suites). No English surface; typed form agrees.

### 68[All]
- D1 circuit 14 DEEP NOTE: All answers whether EVERY selected id matches the shared predicate engine; value = matched = the hit, count = selection size, source 'all'. On an empty selection All is True for every predicate — VACUOUS truth, the classical dual of Dell 67's empty-False; a bare predicate is True on any selection. Read-only. No English surface; typed form agrees.

### 69[None]
- D1 circuit 14 DEEP NOTE: None answers whether NO selected id matches the shared predicate engine; value = matched = the hit, count = selection size, source 'none'. None is the exact DE MORGAN dual of Dell 67: None(lab) == not Any(lab) on every state (proven across four predicates); on an empty selection None is True, and a bare predicate makes None True exactly when the selection is empty. Read-only. No English surface; typed form agrees.

### 84[Copy]
- Deep contract proven (D1 circuit 4, d1_dell84_copy_test): store[copy_<src>] = deepcopy of the source; the destination is derived, never a caller argument; a missing source copies the name string itself; fallback order lab -> selected[0] -> "object"; publishes last_result; copies persist across save/load; English "copy A" routes its typed source through the generalized route (router arg-loss defect found and fixed in the same circuit).

### 85[Move]
- Deep contract proven (D1 circuit 5, d1_dell85_move_test): store[dest] = store.pop(src) — the same object relocates (identity, not a copy); lab is src>dest, partition on the first ">"; an existing destination is overwritten; dest == src is a named no-op success ("Move same identity", fresh matched result cell); failures malformed_move / move_missing publish failure cells; NOT in the English blocked set (86/87/88 are) — the English route executes "move A to B" with its operands and the moved state persists; at the REPL surface, however, the word "move" is captured by avatar navigation, so the REPL user path for 85 is the Mandell seed line.

### 86[Delete]
- Deep contract proven (D1 circuit 6, d1_dell86_delete_test): key = the whole lab; store wins over groups for a shared name (two deletes peel store, then group); NO_AUTHORITATIVE_RESULT — even a successful delete publishes an explicit non-matched result cell, distinct from the failure cell that carries delete_missing:{key} (empty key: delete_missing:empty — signature failures text synced to this truth in the same circuit); English delete is blocked_with_reason (operand-confirmation policy) at the route and at the REPL, and negated English never becomes a delete intent; deletions persist.

### 87[Replace]
- Deep contract proven (D1 circuit 7, d1_dell87_replace_test): identity rename old>new; an occupied destination REFUSES (replace_occupied:{new}, zero mutation — the MPC-012 §0 / MPC-011 J-decision in the executor's comment; the deliberate contrast with Dell 85 Move, which overwrites); replace_missing:{old} for an absent source (bare form: replace_missing:); empty new and new == old are no-op successes; signature failures text + derived_from range synced to the code in the same circuit (the refusal was missing from the signature); English replace is blocked_with_reason; renames persist.

### 88[Patch]
