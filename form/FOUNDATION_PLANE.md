## Holdable was a metaphor
Not a physical toy in the hand. Means: **control perspective** and **location on the plane**.

## Dell Matrix = the plane
- Flat geometric plane (table-like), not required to look like furniture
- You **place** things on it: 3D concepts (e.g. harmonic cube), 2D concepts, **words**
- Same foundation under every view

## Perspective modes (same matrix, different view)
| Mode | What you see |
|------|----------------|
| **Table** | Standing before the plane; place/move units |
| **Top-down / page** | Face-down on the plane; like a page; zoom into a square = that cell’s page (words/info) |
| **Cube-based** | Grid/cubic organization of relations |
| **Circle-based** | Circular plane; harmony around |
| **Flower of Life / Vesica** | Overlap relations; left + right → middle relation |
| **Sphere** | Expand; more of the information field visible |

Zoom out → back to table/plane overview.

## Units (ideas / concepts)
- One concept can **display** as cube, sphere, seed/flower, building, words, etc.
- Display is **perception skin** — underlying unit is the same
- Change cube → circle: same unit, circular operation view

## Connection vs sandbox
| State | Effect |
|-------|--------|
| **On plane (connected)** | Resonates / enhances other units on the matrix |
| **In box / void / sandbox** | Isolated; units inside affect each other only; not the outside matrix |
| Visible mark | Box/ring so you still see isolation when zoomed out |

## Harmonic cube
3D **concept** placed on the plane. Zoom into it while connected → work it → enhances the rest. Box it → work alone.
